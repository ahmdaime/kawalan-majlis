Kekunci: 1–8 input ke Preview · Enter CUT · F FADE · Space butang kuning · Esc SOROK · → Seterusnya. Video penuh tetap dalam OBS dan Multiview; gambar di sini dikemas kini beberapa kali sesaat.

Diambil dari cara kerja vMix

  • Preview (oren) di kiri, Program (merah) di kanan, peralihan di tengah.
  • Deretan input bernombor dengan gambar kecil. Sempadan oren = Preview, merah = Program.
  • T-bar, FTB, jam dan status REC / LIVE di atas.

Lebih baik untuk majlis sekolah

  • Nama penerima ialah overlay dengan nombor giliran dan kunci lagu (Panel Pengarah).
  • Muzik latar dikecilkan sendiri bila lagu aturcara dimainkan (ducking). vMix tiada ini.
  • Klik input tidak sekali-kali membisukan mikrofon.
  • Kiraan bingkai tercicir sentiasa nampak semasa live.

Cara ia berfungsi

  • OBS kekal sebagai enjin: siaran, rakaman, kad tangkap.
  • Tetingkap ini satu panel OBS yang ditarik keluar dan dibesarkan, atau dibuka di skrin kedua.
  • Sekolah yang guna switcher boleh sembunyikan deretan input.
